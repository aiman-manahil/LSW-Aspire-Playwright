
# QA Automation Demo – Playwright + Pytest

This project demonstrates a structured QA automation framework using Playwright with Pytest and Page Object Model (POM).

## Features

* Page Object Model design for scalability
* Automated UI test cases
* Clear test structure and reusable components
* Assertions for functional validation

## Test Scenarios Covered

* User login (valid & invalid cases)
* Form submission
* Basic navigation and Filters

## Tech Stack

* Python
* Playwright
* Pytest

## Purpose

This project reflects my approach to building maintainable automation frameworks and ensuring reliable product quality through structured testing.
